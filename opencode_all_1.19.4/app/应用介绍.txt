OpenCode（列表版介绍）

OpenCode 是开源 AI 编程智能体（MIT 协议，上游：https://github.com/anomalyco/opencode ）。
本包将上游官方 v1.19.3 二进制打包为飞牛 fnOS 应用：安装后作为后台服务运行，
浏览器打开应用即可使用其自带 Web 界面，无需命令行。

主要功能：
- 在你指定的工作目录内，让 AI 阅读代码、修改文件、执行命令、运行测试
- 支持 75+ 模型服务商：Claude、GPT、Gemini、DeepSeek 等，也可接本地 Ollama / vLLM 等 OpenAI 兼容端点
- 自带 Web 界面，会话管理、执行日志可视化、文件拖拽上传、权限交互确认
- 多会话并行，长任务后台运行，随时断开重连

访问方式：
- 在飞牛桌面点击应用图标即可，界面在应用窗口内直接打开（登录飞牛即可，无需额外密码、无需跳转网页）

数据存放位置：
- 项目文件（你与 AI 共同编辑的代码与文档）：<code>文件管理 → 管理员视角 → 设备全部文件 → 存储空间1（按实际存储空间为准）→ @appdata → opencode → projects → 我的项目</code>（已在应用的访问权限默认授权中，AI 可直接读写）
- 应用数据（API Key、配置、会话记录）：<code>文件管理 → 管理员视角 → 设备全部文件 → 存储空间1（按实际存储空间为准）→ @appdata → opencode</code>，卸载默认保留
- 该路径需以管理员账号在文件管理中查看（需要管理员账号（普通成员无此入口））

安全设计：
- 应用以专用低权限系统用户运行（非 root）
- 文件访问仅限项目目录（应用数据区内，见下方「数据存放位置」）
- 应用不做 TCP 监听，经飞牛统一网关代理访问（鉴权由飞牛门户承担），不暴露公网

注意事项：
- 使用 AI 功能需自行配置模型 API Key 或本地模型地址（配置方法见应用内引导）
- AI 会在服务器真实 shell 中执行命令，请勿将系统敏感目录授权给本应用
- 本包为社区第三方打包，上游官方团队未参与制作；包内程序为上游官方原版二进制

【付费说明】本应用完全免费开源，打包分发不收取任何费用；使用第三方模型服务产生的费用由模型厂商收取，与飞牛官方及打包者无关。
